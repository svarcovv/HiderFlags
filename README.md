# HiderFlags (Minecraft 1.21+)

Легковесный плагин, который позволяет одной командой скрыть все стандартные атрибуты и флаги с предметов. 

## Команды (Commands)
* `/hidehand` - Скрыть атрибуты и флаги с предмета в основной руке. 
* `/hideinv` - Скрыть атрибуты и флаги со всех предметов в инвентаре.

## Права (Permissions)
* `hiderflags.use` - Полный доступ к командам. 

## Установка
* Скачайте готовый `.jar` файл из раздела **[Releases](https://github.com/svarcovv/HiderFlags/releases/tag/v1.0.0)**.

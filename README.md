# HiderFlags

Плагин для Paper 1.21.4 и Java 21. Скрывает технические подсказки предметов, сохраняя их характеристики, эффекты, зачарования, название и описание.

[Скачать HiderFlags 1.1.0](https://github.com/svarcovv/HiderFlags/releases/download/v1.1.0/HiderFlags-1.1.0.jar)

## Команды

- `/hidehand` - скрыть подсказки предмета в основной руке.
- `/hideinv` - скрыть подсказки всех предметов в инвентаре, включая броню и вторую руку.

Число в ответе `/hideinv` означает количество изменённых слотов. Уже обработанные предметы повторно не учитываются.

## Права

`hiderflags.use` - доступ к обеим командам. По умолчанию доступно операторам.

## Предметы

Скрываются атрибуты оружия и брони, зачарования и содержимое зачарованных книг, эффекты зелий и стрел, цвет и отделка брони, неразрушимость, ограничения приключенческого режима и дополнительные подсказки предметов, включая название композиции на пластинках.

Предметы помечаются в PDC. Скрытие обновляется при входе, открытии и изменении инвентаря, зачаровании, а также при подготовке результатов наковальни, кузнечного стола, точила и крафта, если результат сохранил метку. Новые предметы из обычных рецептов автоматически не помечаются.

Фиктивный атрибут старой версии `hiderflags:dummy_attribute` удаляется при обработке. Если он был единственным модификатором, восстанавливаются стандартные характеристики предмета. Остальные пользовательские модификаторы сохраняются.

# HiderFlags (Minecraft 1.21+)

**HiderFlags** - это очень простой и легковесный плагин, который позволяет одной командой скрыть все стандартные атрибуты и флаги с предметов (например, строчки *+9 Урона*, *Защита IV*, и т.д.) 
Больше не нужно искать громоздкие моды или огромные плагины, чтобы скрыть некрасивые системные надписи. Все скрытия проходят на уровне сервера. Соответственно не будет такого что атрибуты снова станут видны.

===

## Особенности (Features)
* Работает на актуальной версии **Minecraft 1.21+**.
* Практически не потребляет ресурсы сервера.
* Вообще не требует настройки.

## Команды (Commands)
* `/hidehand` - Скрыть атрибуты и флаги с предмета в основной руке. 
* `/hideinv` - Скрыть атрибуты и флаги со всех предметов в инвентаре.

## Права (Permissions)
* `hiderflags.use` - Полный доступ к командам. 

===

## Как установить
1. Скачайте готовый `.jar` файл из раздела **[Releases](https://github.com/svarcovv/HiderFlags/releases/tag/v1.0.0)**.
2. Перетащите его в папку `plugins` вашего Paper/Purpur сервера.
3. Перезапустите сервер.
